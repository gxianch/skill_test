# Triage 标签

工程技能使用五类标准 triage 角色。本文件把这些角色映射到当前仓库 issue tracker 使用的实际标签字符串。

| 技能中的标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，可交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 triage 角色时，使用上表对应的标签字符串。
