# Issue tracker：GitHub Issues

本仓库使用 GitHub Issues 管理 issue 和 PRD。

## 仓库

- GitHub 仓库：`gxianch/skill_test`
- Git 远端：`git@github.com:gxianch/skill_test.git`

## 约定

- 当技能要求“发布到 issue tracker”时，使用 `gh issue create` 在 GitHub Issues 中创建 issue。
- PRD 类 issue 使用标题前缀 `PRD:`。
- 已明确、可交给 agent 执行的 issue 添加 `ready-for-agent` 标签。
- issue 正文使用中文，保留必要英文技术名词和机器可读状态标签。

## 本地文档

长期有价值的 PRD 可以同时保留一份在 `docs/prd/` 下，作为仓库文档；真正的任务跟踪以 GitHub Issues 为准。
