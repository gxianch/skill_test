# PRD：macOS 菜单栏语音转文字工具

Status: ready-for-agent

## 问题陈述

Mac 用户需要一个低摩擦、隐私友好的语音转文字输入工具，用于在任意 App 中快速口述短句或段落。系统自带听写和云端工具要么体验不够贴近“按住说话”，要么在隐私、网络依赖、剪贴板污染、应用切换后误粘贴等方面不可控。目标用户希望在 MacBook 上使用一个常驻菜单栏工具：按住一个快捷键说话，松开后本地转写，并把文本插入当前输入位置。

## 解决方案

构建一个 Apple Silicon macOS 13+ 菜单栏 App。用户长按右 Option 开始录音，松开后 App 使用本地 `whisper.cpp` 和默认中文 `base` 模型完成转写。转写成功后，App 将结果自动粘贴到录音结束时的前台 App，并在粘贴后恢复用户原剪贴板。App 提供菜单栏图标、非抢焦点悬浮状态提示、首次权限引导、极简设置页、模型下载和诊断信息复制。

MVP 默认不保留音频、不做完整历史，只保留最近一次转写文本用于重新复制或重新粘贴。App 独立 DMG 分发，使用 Developer ID 签名和公证，暂不进入 Mac App Store。

2. 作为 Mac 用户，我希望松开右 Option 后才开始转写，以便我能精确控制一句话何时结束。
3. 作为 Mac 用户，我希望 App 常驻菜单栏，以便它随时可用且不占用 Dock 空间。
4. 作为 Mac 用户，我希望 App 使用本地转写，以便我的语音不需要离开设备。

6. 作为 Mac 用户，我希望转写成功后自动粘贴，以便不需要手动复制和粘贴。
7. 作为 Mac 用户，我希望自动粘贴后恢复原剪贴板，以便语音输入不会覆盖我复制的链接、密码或代码片段。

19. 作为 Mac 用户，我希望失败时看到友好的错误提示，以便不需要阅读原始日志也能理解问题。
20. 作为 Mac 用户，我希望可以复制诊断信息，以便寻求帮助时能提供环境和错误详情。
21. 作为 Mac 用户，我希望诊断信息不包含音频和转写文本，以便支持数据不会泄露隐私内容。
22. 作为 Mac 用户，我希望录音音频用完即删，以便 App 不会积累敏感语音数据。
23. 作为 Mac 用户，我希望默认不保存完整转写历史，以便私人口述内容不会被长期存储。
24. 作为 Mac 用户，我希望最近一次转写可以恢复，以便失败后能重新复制或重新粘贴。
25. 作为 Mac 用户，我希望有一个简单设置窗口，以便调整核心行为而不被复杂偏好项干扰。
26. 作为 Mac 用户，我希望开机自启默认关闭，以便安装 App 不显得侵入。
27. 作为 Mac 用户，我希望关闭设置窗口后菜单栏 App 继续运行，以便工具仍然随时可用。
28. 作为 Mac 用户，我希望菜单里有明确的退出项，以便可以完全停止后台 App。
29. 作为 Mac 用户，我希望录音或转写进行中再次触发时不会启动第二个任务，以便并发任务不破坏状态。
30. 作为 Mac 用户，我希望转写进程有超时处理，以便本地进程卡死时 App 不会一直不可用。
31. 作为 Mac 用户，我希望成功或失败时都不要播放声音，以便频繁听写时保持安静。
32. 作为 Mac 用户，我希望悬浮状态提示不抢焦点，以便它不会打断当前输入 App。
33. 作为 Mac 用户，我希望完成后的状态提示很快消失，以便屏幕不会被长期占用。
34. 作为 Mac 用户，我希望默认模型优先低延迟，以便短句语音输入响应更快。
35. 作为开发者，我希望转写能力封装在稳定模块后面，以便后续可以替换 `whisper.cpp` 或增加其他本地引擎。
36. 作为开发者，我希望模型管理与 UI 解耦，以便下载、校验和模型状态能在不启动 App 的情况下测试。
37. 作为开发者，我希望剪贴板处理独立封装，以便剪贴板保存、替换、粘贴和恢复可以确定性测试。
38. 作为开发者，我希望权限检查独立封装，以便 UI 能响应权限状态而不重复调用系统 API。
39. 作为开发者，我希望录音和转写流程由小型状态机协调，以便非法状态切换明确且可测试。
40. 作为开发者，我希望使用 GitHub Issues 管理 PRD 和 issue，以便规格和任务可以在远端协作。

## 实现决策

- 使用 Swift、SwiftUI 和 AppKit 构建原生 macOS 菜单栏 App。
- 支持 Apple Silicon 上的 macOS 13 Ventura 或更高版本。
- MVP 不承诺 Intel Mac 支持；检测到 Intel Mac 时显示“不支持或实验性支持”提示。
- 使用 `whisper.cpp` 作为本地转写引擎。
- 将 `whisper.cpp` CLI 可执行文件打包进 App 资源。
- 默认模型首次启动时下载，不打包进 App。
- 默认使用中文 `base` 模型，优先保证 MVP 低延迟。
- 模型文件存放在 Application Support。
- 临时音频文件存放在 Caches，转写后删除。
- 模型下载完成后执行 checksum 校验，通过后才标记为可用。
- MVP 只保留一个 active 模型。
- 使用右 Option 长按作为主触发方式。
- 通过 event tap 捕获并拦截右 Option 事件，避免目标 App 接收到该修饰键交互。
- event tap 和自动粘贴都依赖辅助功能权限。
- 录音依赖麦克风权限。
- 缺少辅助功能权限时，不承诺右 Option 语音输入可用；只显示授权修复路径。
- 缺少麦克风权限时，禁用录音并显示授权修复路径。
- 首次启动提供麦克风和辅助功能权限引导。
- 使用菜单栏入口承载常驻状态和操作入口。
- 关闭设置窗口只隐藏窗口，App 继续运行。
- 菜单栏菜单提供明确的退出命令。
- 开机自启默认关闭，设置中提供基于系统登录项 API 的开关。
- 使用非激活悬浮状态面板展示录音中、转写中、成功和失败状态。
- 悬浮状态提示固定在当前屏幕顶部中间。
- MVP 不播放成功或失败提示音。
- 右 Option 按下后延迟 150ms 再开始录音，降低误触。
- 短于 300ms 的录音直接丢弃，不调用转写。
- 单次录音最长 60 秒，达到上限后自动停止并开始转写。
- MVP 不实现 VAD 自动断句。
- 录音或转换后的音频格式为 16kHz、单声道、WAV/PCM 16-bit。
- 同一时间只允许一个录音或转写任务。
- 转写在后台运行，UI 保持响应。
- 转写进程超时时间为 30 秒；超时后杀掉子进程并显示友好失败提示。
- 录音结束时记录前台 App。
- 转写完成时如果前台 App 未变化，则自动粘贴。
- 转写完成时如果前台 App 已变化，则只复制结果并显示提示，不自动粘贴。
- 自动粘贴前保存原剪贴板。
- 将转写文本写入剪贴板，模拟 Cmd+V，500ms 后恢复原剪贴板。
- 转写为空或失败时不粘贴，并恢复原剪贴板。
- 不保存音频历史。
- 不保存完整文本历史。
- 只保留最近一次转写文本，用于重新复制或重新粘贴。
- 提供极简设置窗口，分为“权限”“快捷键”“模型”“行为”四块。
- 模型下载状态包括：未下载、下载中、校验中、可用、失败。
- 模型下载失败时显示失败状态和重试操作。
- 提供友好错误提示和“复制诊断信息”操作。
- 诊断信息包括 App 版本、macOS 版本、芯片类型、权限状态、模型路径、模型大小、最近错误码和 stderr 摘要。
- 诊断信息不得包含音频内容或转写文本。
- 使用 Developer ID 签名和公证进行独立分发。
- MVP 使用 DMG 安装包分发。
- MVP 不实现自动更新，只提供手动检查更新或下载链接。

主要模块：

- App 外壳与菜单栏生命周期模块：负责启动、菜单栏入口、设置窗口展示、退出行为和登录项设置。
- 权限协调模块：暴露麦克风和辅助功能权限状态，并提供修复入口。
- 快捷键 event tap 模块：负责右 Option 按下/松开检测、事件拦截、防抖和权限相关可用性。
- 录音管线模块：负责麦克风采集、时长限制、短录音丢弃、音频转换和临时文件清理。
- 转写运行模块：负责调用打包的 `whisper.cpp` CLI、超时、进程取消、stderr 捕获和结果解析。
- 模型管理模块：负责模型下载、checksum 校验、active 模型路径、重试状态和模型可用性。
- 前台 App 保护模块：负责记录录音结束时的前台 App，并在粘贴前比较是否变化。
- 剪贴板与粘贴执行模块：负责剪贴板保存、Cmd+V 模拟、恢复时机和失败回滚。
- 状态悬浮层控制模块：负责录音中、转写中、成功和失败的非激活悬浮信息。
- 设置视图模型：组合权限、模型、快捷键和行为状态，供 SwiftUI 设置窗口使用。
- 诊断信息收集模块：生成不含隐私内容的支持诊断文本。
- 会话状态机：协调 idle、pending-recording、recording、transcribing、pasting、copied-only、failed、permission-blocked 等状态。

应优先把模型管理、转写执行、剪贴板处理、权限状态和会话状态机提取为深模块。这些模块用小接口封装高价值行为，可以在不运行完整 macOS UI 的情况下测试。

## 测试决策

- 测试应验证外部行为和状态转换，不测试私有方法名或精确 UI 布局等实现细节。
- 单元测试会话状态机，覆盖 idle、pending-recording、recording、transcribing、pasting、copied-only、failure、timeout、permission-blocked 等状态转换。
- 单元测试模型管理模块，覆盖下载成功、checksum 失败、失败后重试和 active 模型状态。
- 使用假的 CLI 进程抽象测试转写运行模块，覆盖成功、空输出、stderr 失败、超时和取消。
- 在可行范围内用假的音频输入测试录音管线，覆盖短录音丢弃、录音时长上限和临时文件清理。
- 使用可注入 pasteboard 抽象测试粘贴执行模块，覆盖保存、替换、请求粘贴、延迟恢复和失败回滚。
- 使用可注入前台 App 身份测试前台 App 保护模块，覆盖 App 未变时粘贴和 App 改变时只复制。
- 使用假的权限提供者测试权限协调模块，覆盖已授权、已拒绝和未知状态。
- 测试诊断信息收集模块，确保包含环境和错误元数据，同时排除音频和转写文本。
- 使用假的权限、录音器、转写器、前台 App 和剪贴板，为完整会话协调器增加集成式测试。
- 手工验收必须覆盖首次权限引导、模型下载成功、模型下载失败后重试、右 Option 长按录音、短按不转写、转写成功后自动粘贴并恢复剪贴板、前台 App 改变后只复制不粘贴、转写失败后不污染剪贴板。
- 当前工作区没有既有代码和测试套件，第一版实现会建立测试先例。模块级行为优先使用 Swift XCTest；系统权限、event tap 和实际粘贴到第三方 App 的路径用聚焦手工 QA。

## 不在范围内

- 云端转写 API。
- 本地和云端混合 fallback。
- Intel Mac 性能支持或支持承诺。
- Mac App Store 分发。
- 自动更新。
- 完整转写历史和搜索。
- 音频历史或音频回放。
- VAD 自动断句。
- 按一下开始、再按一下结束的切换式录音。
- MVP 右 Option 行为之外的自定义快捷键录制 UI。
- 多模型库管理。
- 默认使用 `small` 或 `medium` 模型。
- 自动语言识别。
- 按 App 配置不同行为规则。
- 粘贴前预览确认 UI。
- 完整日志查看器。
- 遥测或分析。
- 团队、账号或同步能力。
- iOS、iPadOS、Windows、Linux 或浏览器版本。

## 补充说明

- 本 PRD 来自一次已冻结的 `grill-me` 设计会话，剩余选择都按推荐方案定案。
- MVP 优先优化低延迟、本地隐私输入，不追求最高转写准确率。
- 最高技术风险是仅右 Option 的全局事件捕获、辅助功能权限体验、剪贴板恢复时机可靠性，以及 `whisper.cpp` 的打包、签名和公证。
- 隐私应作为默认行为而不是后期设置：不保留音频、不保留文本历史、诊断信息不包含口述文本。
